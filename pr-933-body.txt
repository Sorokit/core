## Summary

Adds `ChangeTrustBuilder` for creating, updating, and removing trustlines with a fluent API and comprehensive validation.

## Changes

### ChangeTrustBuilder Class
Added new `ChangeTrustBuilder` class with chainable API:

```ts
// Create trustline with default maximum limit
buildChangeTrust(context)
  .asset("USDC", "GISSUER...")
  .build()

// Create trustline with custom limit
buildChangeTrust(context)
  .asset("EURC", "GISSUER...")
  .limit("1000")
  .build()

// Remove trustline
buildChangeTrust(context)
  .asset("USDC", "GISSUER...")
  .limit("0")
  .build()
```

### Features
- ✅ **Create trustlines** - Accept issued assets with optional limit
- ✅ **Update limits** - Change existing trustline limits
- ✅ **Remove trustlines** - Set limit to "0" to remove
- ✅ **Asset validation** - Ensures asset is not native XLM
- ✅ **Limit validation** - Non-negative, max 7 decimals
- ✅ **Fluent API** - Chainable methods for developer experience
- ✅ **Asset flexibility** - Accepts Asset instances or code/issuer pairs

### Validation Rules
1. **Asset required** - Cannot build without specifying asset
2. **No native XLM** - Trustlines only for issued assets
3. **Non-negative limits** - Rejects negative values
4. **Decimal precision** - Maximum 7 decimal places
5. **Valid asset codes** - 1-12 alphanumeric characters
6. **Valid issuer** - Must be valid Stellar public key

Factory function and class available:
```ts

// or
const builder = new ChangeTrustBuilder(context);
```
